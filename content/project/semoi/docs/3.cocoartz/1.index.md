코코아츠(CocoArtz)는 아이소메트릭(2.5D) 맵 위를 캐릭터가 돌아다니는, 디스코드와 비슷한 커뮤니티 공간입니다. 마을에서 다른 사람과 함께 걷고 이야기하고, 게시판과 위키에 글을 남기고, 모은 재화로 아바타와 내 방을 꾸밉니다.

서버는 커뮤니티마다 직접 설치해 운영합니다. 각 서버는 ActivityPub으로 마스토돈·미스키 같은 다른 페디버스 서버, 그리고 다른 코코아츠 서버와 연결됩니다. 소스 코드는 [GitHub](https://github.com/jyhyun1008/cocoartz)에 공개되어 있습니다.

- 마을에서 움직이는 법과 재화 모으기는 [마을과 캐릭터](/project/semoi/docs/cocoartz/village)에 있습니다.
- 아바타 파츠와 방 꾸미기, 농사는 [상점과 내 방](/project/semoi/docs/cocoartz/shop-room)에서 다룹니다.
- 채팅, 게시판, 위키, 타임라인은 [채널](/project/semoi/docs/cocoartz/channels)에 정리되어 있습니다.
- 다른 서버와 연결하는 방법은 [페디버스 연결](/project/semoi/docs/cocoartz/fediverse)을 참고하세요.

## 서버 구조

코코아츠 서버 하나에는 여러 **채널**이 있습니다. 채널 이름과 구성은 관리자가 자유롭게 정하기 때문에 서버마다 다를 수 있습니다.

| 채널 | 하는 일 |
| --- | --- |
| 마을 | 캐릭터가 돌아다니는 기본 맵입니다. 로그인하면 항상 여기서 시작합니다. |
| 게시판 | 글과 사진을 올리고 댓글·좋아요·리액션을 남깁니다. |
| 채팅방 | 맵 위의 다른 사람과 실시간으로 대화합니다. |
| 음성 채팅방 | 채팅 내용을 TTS(음성)로 읽어줍니다. |
| 위키 | 다 같이 쓰고 고치는 문서 공간입니다. |

화면 왼쪽 사이드바에 채널 목록이 있고, 그 위에는 팔로우한 사람들의 글을 모아 보는 **타임라인**이 항상 고정되어 있습니다. 화면 상단의 **서버 정보**, **멤버**, **알림** 아이콘은 어느 채널에서나 쓸 수 있습니다.

## 시작하기

1. 로그인 화면의 **회원가입** 탭에서 핸들(영문·숫자 아이디), 이메일, 비밀번호(6자 이상)를 입력합니다. 핸들은 나중에 바꿀 수 없고, 화면에 보이는 닉네임은 언제든 바꿀 수 있습니다.
2. 서버 설정에 따라 바로 로그인되거나, 이메일 인증 또는 관리자 승인을 거친 뒤 로그인할 수 있습니다.
3. 가입이 끝나면 서버가 정한 가입 보너스 재화(기본 100 코코아)를 받고, 기본 헤어·옷·얼굴을 갖춘 캐릭터로 마을에서 시작합니다.

비밀번호를 잊었다면 로그인 탭의 "비밀번호를 잊으셨나요?"에서 재설정 메일을 받을 수 있습니다. 서버가 이메일 발송을 꺼 두었다면 관리자에게 문의하세요.

## 탈퇴

설정 페이지 맨 아래의 **탈퇴하기**로 언제든 탈퇴할 수 있습니다. 되돌릴 수 없으며, 그동안 쓴 글·댓글·채팅은 "탈퇴한 유저가 작성한 게시물입니다"로 바뀝니다. 연합된 다른 서버에도 계정 삭제가 전달됩니다.
