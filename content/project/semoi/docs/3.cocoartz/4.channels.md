## 채팅

- <kbd>Enter</kbd>로 보내고 <kbd>Shift</kbd>+<kbd>Enter</kbd>로 줄을 바꿉니다. 한글 조합 중에 엔터를 눌러도 실수로 전송되지 않습니다.
- 마크다운과 이모지를 쓸 수 있고, 서버에 등록된 커스텀 이모지는 이모지 피커의 **커스텀** 탭에서 고릅니다.
- 메시지 아래 **+**로 이모지 리액션을 붙이고, 같은 리액션을 다시 누르면 취소합니다.
- 내 메시지는 수정·삭제할 수 있습니다. 수정한 메시지에는 **(수정됨)**이 붙습니다.
- 채팅창은 화면 아래 작은 창과 화면 가운데 큰 창 사이를 오갈 수 있습니다.

### 음성 채팅방

메시지를 보내면 브라우저가 보낸 사람 이름과 내용을 기기의 기본 한국어 음성으로 읽어줍니다. 이모지 피커와 리액션은 없고, 수정·삭제와 뮤트는 일반 채팅과 같습니다.

## 게시판

- **+ 새 글**에서 제목과 본문을 씁니다. 본문은 **작성**과 **미리보기** 탭을 오가며 마크다운으로 쓰고, 엔터 한 번으로 줄이 바뀝니다.
- 서버에 저장소가 설정되어 있다면 **📎 파일 첨부**로 이미지, 문서, 압축 파일, 음원, 동영상을 최대 20MB까지 올립니다.
- 글에는 좋아요, 이모지 리액션, 댓글을 남길 수 있고, **공유** 아이콘으로 링크를 복사합니다.
- 관리자가 **갤러리 보기**로 설정한 게시판은 정사각형 썸네일 카드로 보입니다.
- 글은 20개씩 불러오고, **더보기**로 이어서 봅니다.

내 글은 언제든 삭제할 수 있습니다. 수정은 연합 게시판이 아닐 때만 할 수 있습니다. 이미 다른 서버로 퍼진 글은 내용이 달라지지 않도록 삭제만 지원합니다.

## 위키

- 로그인한 사람이라면 누구나 새 페이지를 만들고 기존 페이지를 고칠 수 있습니다. 읽기는 로그인하지 않아도 됩니다.
- 본문에 `[[페이지 이름]]`을 쓰면 그 이름의 페이지로 가는 링크가 됩니다. `[[페이지 이름|표시할 글자]]`처럼 보이는 문구를 바꿀 수 있습니다. 아직 없는 페이지를 먼저 링크해 두고 나중에 만들어도 됩니다.
- 위키 채널에 처음 들어가면 가장 먼저 만들어진 페이지가 대문으로 열립니다.
- **이력**에서 이전에 저장된 버전과 편집 시각을 볼 수 있습니다.

## 타임라인

사이드바 맨 위의 **타임라인**에는 내가 팔로우한 사람들의 글과 내 글이 시간순으로 모입니다. 팔로우한 다른 서버 계정의 글과 재게시(부스트)도 함께 보이고, 원격 글에는 어느 서버에서 왔는지 서버 뱃지가 붙습니다. 답글은 타임라인 목록에 따로 나오지 않고 원래 글 안에서 볼 수 있습니다.

## 팔로우와 뮤트

다른 사람의 프로필에서 **팔로우**를 누르면 그 사람의 새 글이 타임라인에 모입니다. 상대가 팔로우를 직접 승인하도록 설정했다면 **요청됨** 상태로 기다립니다.

**소프트 뮤트**는 그 사람의 글과 댓글을 "뮤트된 게시물입니다"로 가리고 펼쳐 볼 수 있게 하며, **하드 뮤트**는 아예 보이지 않게 합니다. 상대에게는 알려지지 않습니다. 글·댓글·채팅의 작성자 이름 옆 뮤트 아이콘에서도 바로 뮤트할 수 있습니다.

## 설정

| 항목 | 설명 |
| --- | --- |
| 화면 테마 | 다크 모드와 라이트 모드를 바꿉니다. |
| 화면 효과 | 카메라 흔들림과 창을 열 때 배경이 흐려지는 효과를 켜고 끕니다. 저사양 기기에서 맵이 버벅이면 꺼 보세요. |
| 이메일 인증 | 서버가 이메일 발송을 켜 둔 경우, 인증 메일을 다시 받을 수 있습니다. |
| 팔로우 승인 방식 | "새 팔로우를 수동으로 승인"을 켜면 팔로우 요청을 하나씩 승인하거나 거절합니다. |
| 뮤트 목록 | 뮤트한 사람을 모아 보고 해제합니다. |
| 원격 계정 관리 | 다른 페디버스 서버의 계정을 팔로우하거나 언팔로우합니다. |
| 계정 | 로그아웃과 탈퇴 버튼이 있습니다. |

## 알림

화면 상단의 종 아이콘이 알림함입니다. 지금은 누군가 나를 팔로우했을 때 알림이 옵니다. 좋아요, 댓글, 리액션 알림은 아직 지원하지 않습니다.
