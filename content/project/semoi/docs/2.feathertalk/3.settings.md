모든 설정은 이 브라우저에 자동 저장됩니다. 슬라이더를 더블클릭하면 기본값으로 돌아갑니다. 처음이라면 [사용법](/project/semoi/docs/feathertalk/guide)을 먼저 읽어보세요.

## 전체 설정

| 항목 | 설명 |
| --- | --- |
| 얼굴 중심 | 고개를 끄덕이고 돌릴 때 기준이 되는 위치입니다. 코 근처에 두면 자연스럽습니다. 미리보기의 + 십자를 끌어도 됩니다. |
| 얼굴 크기 | 볼록·오목이 적용되는 범위입니다. 점선 원이 얼굴을 감싸도록 맞춥니다. |
| 고개 움직임 | 좌우 회전, 상하 회전, 기울기 강도를 각각 정합니다. |
| 움직임 탄력 | 고개가 멈출 때 살짝 지나쳤다 돌아오는 반동과, 빠르게 움직일 때 늘어나고 납작해지는 정도입니다. 머리카락 흔들림과는 따로 정합니다. |
| 호흡 | 4초 주기로 몸이 살짝 부풀고 머리가 오르내립니다. 흔들림 물리를 켠 레이어도 호흡을 따라 살짝 출렁입니다. |
| 입 움직임 | 켜면 입이 열릴 때 벌린 입이 작은 크기에서 커지고, 닫힐 때 작아졌다가 다문 입으로 바뀝니다. 끄면 그림만 바로 바뀝니다. |
| 눈 눌림 | 켜면 깜빡일 때 뜬 눈을 '눈 영역' 띠 안쪽만 눌러 감기는 과정을 보여줍니다. 눈 높이와 영역 크기는 미리보기의 초록 띠로 확인합니다. |

## 레이어 설정

| 항목 | 설명 |
| --- | --- |
| 이미지 | 주소를 입력하거나 파일을 올립니다. 올린 파일은 이 브라우저에만 저장됩니다. |
| 따라가는 움직임 | **머리**는 고개를 따라 돌아가고, **몸**은 기울기만 따라가며, **고정**은 어떤 움직임도 따라가지 않습니다. 앞에 두는 드럼·피아노 같은 악기는 고정으로 둡니다. |
| 보이는 때 | 항상, 눈 뜰 때, 눈 감을 때, 입 다물 때, 입 열 때 중에서 고릅니다. |
| 표정 | 숫자키 1~0의 표정마다 이 레이어를 보일지 고릅니다. |
| 깊이 | 고개를 돌릴 때 얼마나 움직일지 정합니다. 앞쪽은 많이, 뒤쪽은 반대 방향으로 움직입니다. |
| 볼록 / 오목 | 볼록하면 얼굴 중심 쪽이 가장자리보다 더 많이 움직여서 둥글게 보입니다. |
| 흔들림 물리 | 고개를 움직이면 끝부분이 관성으로 뒤따라 출렁입니다. 머리카락은 '고정선 아래', 리본·장식은 '고정선 위'로 두고, 고정선 높이와 흔들림 세기·탄성·출렁임을 정합니다. 미리보기의 분홍 점선을 끌어 고정선을 옮길 수 있습니다. |
| 클리핑 | 켜면 바로 아래 레이어의 그림 안쪽에만 보입니다. 눈동자를 흰자 바로 위에 두고 켜면 흰자 밖으로 나가지 않습니다. |
| 깜빡일 때 통통 | 켜면 눈을 감을 때 같이 눌렸다가, 뜰 때 탄성 있는 공처럼 살짝 튀었다가 돌아옵니다. |

눈동자 레이어는 보이는 때를 '눈 뜰 때'로, 깊이를 흰자보다 높게 두면 고개를 돌릴 때 시선이 따라가는 느낌이 납니다.

## 라이브 화면

| 항목 | 설명 |
| --- | --- |
| 마이크 민감도 | 목소리를 얼마나 작은 소리부터 인식해 입을 열지 정합니다. |
| 리깅 강도 | 고개 움직임 전체의 크기를 정합니다. |
| 자동 모션 범위 | 마우스를 멈추면 캐릭터가 알아서 둘러봅니다. 낮으면 정면 근처에서만, 높으면 크게 왔다 갔다 합니다. |
| 프레임 | 30fps로 낮추면 컴퓨터 사용량이 절반 가까이 줄어듭니다. 대신 움직임이 조금 덜 부드러워집니다. |
| 웹캠 | 웹캠으로 얼굴 각도를 따라갑니다. 영상은 화면에 띄우거나 어디로 보내지 않습니다. |
| 정면 맞추기 | 정면을 보고 눈을 뜬 채로 누르면, 지금 자세를 정면으로, 지금 눈 뜬 정도를 평소 뜬 눈으로 잡습니다. |
| 좌우 반전 | 켜면 거울처럼, 내가 왼쪽을 보면 캐릭터도 화면 왼쪽을 봅니다. |
| 눈 깜빡임도 | 눈을 확실히 감고 있으면 캐릭터도 감습니다. 얼굴을 놓치면 자동 깜빡임으로 돌아갑니다. 기본은 꺼져 있습니다. |
| 배경색 | 방송 프로그램에서 크로마키로 지울 배경색입니다. |

라이브 중에는 숫자키 1~0으로 표정을 바꿉니다. 브라우저가 WebGL을 지원하지 않으면 이전 버전 화면으로 열 수 있습니다.
