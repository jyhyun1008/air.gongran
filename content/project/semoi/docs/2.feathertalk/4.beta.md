새 기능은 베타에서 먼저 시험하고, 확인되면 정식판에 올립니다. 베타 기능은 바뀌거나 빠질 수 있습니다.

| 화면 | 주소 |
| --- | --- |
| 베타 편집기 · 라이브 | [/beta](https://v2.feathertalk.live/beta) · `/beta/live` |
| 멀티 설정 · 방송 화면 | [/multi](https://v2.feathertalk.live/multi) · `/multi/live` |

베타는 정식판과 설정을 따로 저장합니다. 처음 열 때 정식판 캐릭터를 복사해 오고, 올린 이미지 파일은 정식판과 함께 씁니다.

## 베타 기능

| 기능 | 설명 |
| --- | --- |
| 세로로 긴 그림 | 정사각형이 아닌 전신 그림도 비율을 자동으로 읽어 씁니다. |
| 확대·이동 | 휠이나 두 손가락 핀치로 확대·축소하고, 우클릭·휠 버튼·두 손가락 드래그로 화면을 옮깁니다. **화면 맞춤**으로 처음 구도로 돌아갑니다. |
| 몸 리깅 | 관절 위치를 맞추면 '몸' 레이어가 가장 가까운 뼈를 자동으로 따라갑니다. 몸은 얼굴 각도를 따라 원기둥처럼 돌고, 팔은 어깨에 매달려 흔들리며, 다리는 발을 바닥에 붙인 채 무릎을 굽힙니다. |
| 몸 흔들림 | 스커트, 코트 자락, 꼬리처럼 몸 레이어에도 흔들림 물리를 줄 수 있습니다. |
| 연주 포즈 | 악기를 연주할 때의 동작 1·2를 직접 만들고, 소리가 나는 동안 두 동작을 오가게 합니다. 팔·다리 뼈 길이는 0.7~1.3배로 조절합니다. |
| 캐릭터 슬롯 | 1~0번 캐릭터를 따로 만들어 둡니다. 슬롯마다 레이어와 설정이 따로 저장되고, 탭을 우클릭해 복사·붙여넣기할 수 있습니다. |
| 정리된 설정 화면 | 탭, 접이식 묶음, 시작하기 체크리스트로 설정을 나눠 보여줍니다. |

### 몸 리깅 팁

- 몸 레이어는 그림이 있는 부분에서 가장 가까운 뼈 하나에 통째로 붙습니다. 몸 위쪽, 팔, 다리는 레이어를 나눠 주세요.
- 양팔이나 양다리를 한 장에 그렸다면 반으로 잘라 좌우를 따로 움직입니다. 양다리에 걸친 스커트는 몸 아래쪽에 붙습니다.
- 연주 포즈에서 돌린 뼈에 붙은 레이어가 없으면 화면에서 움직이지 않습니다. 경고가 뜨면 그 부위가 따로 레이어로 나뉘어 있는지 확인하세요.

## 멀티

베타의 1~0번 캐릭터를 16:9 무대 하나에 올리고, 화면 공유로 SYNCROOM 레벨미터나 Discord의 말하는 테두리를 감지해 말하는 캐릭터의 입을 움직입니다. 여러 사람이 함께 하는 합주나 대화 방송을 위한 화면입니다.

1. **화면 캡처 시작**으로 SYNCROOM이나 Discord 창을 공유합니다. 필요하면 자르기 영역을 지정해 사이드바 등을 뺍니다.
2. 무대에 올릴 캐릭터를 켜고, 캐릭터마다 레벨미터나 말하는 테두리 부분을 **감지 영역**으로 지정합니다. 그 영역에 기준 색이 보이면 말하는 것으로 봅니다.
3. 배경, 악기, 로고처럼 말에 반응하지 않는 이미지는 **오브젝트**로 추가합니다.
4. 무대에서 캐릭터와 오브젝트를 끌어 옮기고, 오른쪽 아래 파란 점으로 크기를 바꿉니다.
5. 배경색은 크로마키로 지울 단색(보통 초록 #00ff00)으로 두고 **라이브 시작**을 누릅니다.

감지가 잘 안 될 때는 기준 색, 색 허용 범위, 말하는 중 판정 픽셀 수, 유지 시간을 조절합니다. 멀티 화면은 웹캠 트래킹을 쓰지 않습니다. 캐릭터는 위쪽 **캐릭터 만들기** 탭(베타 편집기와 같은 캐릭터)에서 만듭니다.
